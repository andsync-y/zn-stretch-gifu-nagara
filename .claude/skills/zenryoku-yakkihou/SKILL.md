# 薬機法・景表法チェック

## 前提

当店は**リラクゼーション目的のパーソナルストレッチ専門店**であり、
医業類似行為（治療・矯正）を行う施術所ではない。
したがって効果効能を断定する表現は、たとえ事実であっても書けない。

違反は行政指導・広告アカウント停止に直結する。**迷ったら書かない**。

## 手順（この順で必ず行う）

### 1. 文章を書く／直す

言い換えの型は `docs/yakkihou-ng-ok.md` の表を使う。主要なものだけ再掲する。

| 使わない | 使う |
|---|---|
| 治る／治療／完治 | ケア／アプローチする／向き合う |
| 改善します／効果があります | 体感として／ラクに感じる方が多い／目指す |
| 解消／取れる | すっきり／軽やかに／めぐりをサポート |
| 矯正 | 姿勢を意識しやすい状態へ／可動域にアプローチ |
| 根本改善 | 身体全体のバランスに向き合う／体感軸調整法でアプローチする |
| No.1／絶対／必ず | 事実のみ／一人ひとりに合わせて（個人差がある旨を添える） |

### 2. スクリプトで検査する（目視で済ませない）

```bash
# ファイルを検査
node scripts/yakkihou-ng.mjs src/pages/column/<slug>.astro

# 生成したばかりの本文を検査（保存前でもよい）
printf '%s' "$本文" | node scripts/yakkihou-ng.mjs

# 機械可読な結果が欲しいとき
node scripts/yakkihou-ng.mjs <file> --json
```

NG表現が1つでもあれば**終了コード1**。0になるまで直す。

語のリストを記憶から判定しないこと。人もAIも必ず見落とす。
判定基準は `scripts/yakkihou-ng.mjs` の `NG_PATTERNS` が唯一の定義元で、
`lint-column.mjs`（コラムの品質GATE）と `gbp-post-draft.mjs` も同じ定義を読んでいる。

### 3. 数値・実績の裏取り

NG語が無くても、次に当たるものは書かない。

- **創作した口コミ・症例・体験談**（実在しないお客様を作らない）
- **実在しないスタッフ・施術風景・設備**（AI画像生成でこれを作らない）
- **根拠のないパーセンテージ**（「満足度95%」等。実アンケートが無ければ書かない）
- **本部（FC）の実績を長良店の主語で書く**こと
  - NG「当店は70店舗を展開」→ OK「全力ストレッチは全国約70店舗を展開するブランドです」
- **価格の割引表示で通常価格を併記しない**こと（景表法。表示は税込）

## NGパターンを追加・変更するとき

`scripts/yakkihou-ng.mjs` の `NG_PATTERNS` と `NG_SUGGESTIONS` の両方に足し、
`docs/yakkihou-ng-ok.md` の言い換え表も更新する。そのうえで:

```bash
node --test scripts/test/yakkihou-ng.test.mjs
```

全パターンに言い換え候補があることをテストが検査している（検出だけして直し方が無い状態を防ぐため）。
