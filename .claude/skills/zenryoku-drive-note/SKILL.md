# 成果物をオーナーに届ける

## 大前提：届かない成果物はゼロ点

旧SNS自動運用システムは5週間で約70本の投稿を生成したが、**公開は0件**だった。
理由は品質ではなく、通知が未設定で**誰の目にも触れなかった**こと。

生成した時点では仕事は終わっていない。**多和田さんの手元に届いて初めて終わり**。

## 保存先

`00_Inbox`（フォルダID: `1OWupdmrjMcIK6DEqKRq_x3TFocQlVJwp`）

保管庫の過去ノートを読むときは `10_Notes`（ID: `15AQjKCviyyX9LT-ikPoIYrjfX0buFXOP`）も見る。

## 保存の作法

**ファイル名**：`YYYY-MM-DD_<種別>_<短い識別子>.md`

日付は必ず `date +%Y-%m-%d` で取る（推測で書かない）。

```
2026-08-24_週次経営レビュー.md
2026-08-26_GBP投稿下書き_shisei-taikan.md
2026-08-25_Instagram投稿ドラフト_デスクワークの肩.md
2026-09-10_資金監視_8月分.md
2026-08-28_ループ健全性_異常あり.md
```

**冒頭にフロントマター**：

```markdown
---
created: 2026-08-24
tags: [KPI, 週次レビュー, マーケ, 長良店]
type: note
---
```

**保存方法**：`contentMimeType: text/markdown` かつ `disableConversionToGoogleType: true`。
Googleドキュメントに変換しない（変換すると後続タスクが読めなくなる）。

**既存ファイルは編集しない。** 常に新規作成する。
上書きすると他のタスクや人の書き込みを消す可能性がある。

## 通知

保存したら必ず `PushNotification` を送る。**要点1行**にする。

```
週次経営レビューあり：月商進捗◯%／⚠️警告2件
GBP投稿下書きあり：<記事タイトル>。貼り付けて投稿してください（3分）
Instagram下書き：<テーマ>。本文をコピーして投稿してください（3分）
```

所要時間を書くと着手率が上がる。「確認してください」だけだと後回しになる。

**通知しないケース**：ループ健全性チェックが「全ループ正常」だったとき。
異常が無いのに通知すると、通知そのものが無視されるようになる。

## Driveコネクタが使えないとき

コネクタが紐付いていないタスクでは Drive にアクセスできない。そのときは:

1. **保存は諦めてよいが、生成物は絶対に失わない。**
   投稿本文・レポート全文を**省略せず**報告本文に書き出す。
2. 報告の冒頭に明記する:
   `⚠️ Driveコネクタが未接続のため保存できていません。claude.aiのRoutines設定でこのタスクにGoogle Driveコネクタを紐付けてください`
3. エラーとして異常終了しない。他の成果まで巻き添えで失われる。

**「Driveが使えないので何もしませんでした」は最悪の結果**。
1時間ぶんの作業が消えるうえ、通知も来ないので気づかれない。

## 秘密情報

ノートにも報告にも次を書かない。

- 生の電話番号・メールアドレス・氏名（顧客・スタッフとも）
- ハッシュ値
- 認証情報・APIトークン・環境変数の値

顧客の件数だけを書く（例：「3件登録、1件スキップ」）。
