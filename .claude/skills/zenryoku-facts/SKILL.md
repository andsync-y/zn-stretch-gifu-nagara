| 項目 | 値 |
|---|---|
| 目標 | 2027年1月決算月に月商300万円 |
| 損益分岐（新体制） | 月商 約253.9万円 |
| 毎月の費用目安 | 181〜194万円 |
| KPI3点セット | 新規来店 週30人（月125人）／新規販売率25%／更新販売率50% |
| 月商の計算根拠 | 新規×6,886円 ＋ 回数券本数×52,000円（月41本で約301万） |
| 新規の段階目標 | 100 → 130 → 160 → 200 人/月 |
| 回数券1本あたり広告費 | **実績 約17,900円**（2026-08-03〜08-23：広告費¥233,145 ÷ 13本）。目標は10,000円台前半 |

**指標の定義**（ここを取り違えると全部ずれる）
- 新規販売率 ＝ 回数券販売(新規)本数 ÷ 新規来店数
- 更新販売率 ＝ 更新販売本数 ÷ 使い切り人数
- 実来店の目安 ＝ 予約アクション（click_reserve / click_line / click_tel）× **0.17〜0.19**

> ⚠️ **2026-08-24 訂正。** ここは長らく「× 0.6〜0.7」と書かれていたが、**実測は0.17〜0.19**で
> 3.5倍の過大評価だった。この係数で新規ペースを推定すると、実際19人/週の週を60人/週と報告する。
> **数字を出す前に必ず `docs/metrics-definitions.md` を読むこと。**

⚠️ **推定と実数が両方あるときは、常に実数（店舗システム / KPIシート）を採る。**
広告データからの推定は、実数が取れないときの代用でしかない。
