# 広告バナーの背景素材

`scripts/gen-ad-creative.mjs --bg-dir assets/ad-bg` がここを見る。

## 置き方

`scripts/ad-creatives.json` の案IDと**同じ名前**にする。拡張子は jpg / jpeg / png / webp。

| ファイル名 | 対応する案 |
|---|---|
| `E_desk.jpg` | デスクワーク（座りっぱなしの腰・肩） |
| `F_private.jpg` | 完全個室（人目が気にならない） |
| `G_shoulder.jpg` | 肩・腰の重さ（7月の構成の再現） |

## 素材選びの条件

文字は**左上から中央左**に載る（見出し・75%OFFバッジ・価格・店舗情報）。
そのため素材は次を満たすものを選ぶ。

- **被写体が右寄り、または右下にあること。** 左半分が空いている構図
- 正方形に切っても成立すること（1080×1080に `fit: cover` で切る）
- 明るすぎないこと。文字は濃紺なので、左側が白飛びしていると読めない

うまく載らない場合は、`gen-ad-creative.mjs` の `overlaySvg()` で文字の位置を調整する。

## やらないこと

- **AIで店舗やスタッフの「写真」を作らない。** 実在しない店内写真になる
- 価格の文字を画像に焼き込んだ素材をそのまま使わない。
  価格は `ad-creatives.json` の1か所で管理し、**合成側で描く**（変更漏れと二重表示を防ぐため）
