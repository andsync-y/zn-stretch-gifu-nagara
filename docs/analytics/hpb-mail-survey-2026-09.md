## 方法論として分かったこと

1. **アンケートはリピーターにも出る。** 設問が「最初に知ったきっかけ」なので、
   広告の直近効果を見るときは**初回クーポン利用の予約だけ**を分母にする
2. **`[新規]` タグでは初回判別できない。** 初回クーポンを使っていても付いていない例が多数。
   **判別はクーポン名（【初回…】）で行う**
3. **回答は自由記述で、正規化が必要。** 実際の表記：
   - →1：`1` / `１` / `【1】ホットペッパーで検索`
   - →2：`2` / `２番です` / `Instagram` / `facebookの広告` / `インスタ` / `【2】Instagram・Facebookの広告`
   - →3：`3` / `【3】` / `Google検索` / `【3】Google検索`
4. **キャンセルが追える。** 店舗システムの来店記録には残らない。今回は初回16件中1件（Meta経由・6.3%）
5. **【3】Google検索・広告 は自然検索・マップ・広告が分離できない。** 9/28のGoogle判定にはそのまま使えない

## 提案（HPB側の設定変更。オーナーの操作が必要）

- 【3】を「Google検索」と「Googleマップ」に分ける（広告判定の材料になる）
- 【7】LINE を足す
- 回答欄を自由記述から番号選択にできるなら変える（HPBの仕様次第）
