# 広告運用ガードレール（デイリー監視Routine用・オーナー承認済みルール）

最終更新: 2026-08-07（オーナー指示反映）

## 予算
- 総広告費の上限は ¥11,000/日（Meta ¥3,000＋Google ¥8,000）。増額はオーナー承認必須。
- 媒体間・広告セットの予算変更は1日±20%以内。

## 自動停止
- 広告単位でCPA（spend÷GA4予約アクション）が基準の2倍超を3日連続 → pause_ad＋通知。
- 基準: Google ¥1,089/アクション、Meta 暫定¥6,000（/lp切替後1週間で再設定）。

## Google検索語句の除外キーワード
- 除外してよいのは「明らかに無関係」のみ：求人・採用・学校・資格・器具購入・他県の地名など。
- 【オーナー指示 2026-08-07】マッサージ・もみほぐし・タイ古式・整体などの手技系ワードは
  当店の見込み客が検索する関連語のため除外禁止。迷ったら除外せず報告のみ。

## 評価の前提
- 「予約アクション」= HPB予約ページへのクリック等であり予約完了ではない。
  報告には常にこの前提を添える。実予約はサロンボードの数字が正。
