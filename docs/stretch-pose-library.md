# ストレッチ挿絵ライブラリの拡張ガイド

現在32ポーズ（シート1＝オーナーがChatGPTで作成した設定表、シート2＝APIで生成した続編をオーナーが合格判定）。
残バックログの必要ポーズを棚卸しした結果、**あと1シート（16ポーズ）でほぼ全記事をカバーできる**。
ストレッチの標準レパートリーは有限（実質60〜80種）で、記事側は同じポーズを使い回すため、
ライブラリは数回の拡張で収束する。

## 拡張の手順（API生成・2026-08-07にシート2で検証済み）

1. Claudeが `scripts/gen-pose-sheet.mjs` で続編シートの候補を生成
   （gpt-image-2 / 元シートを参照画像に「続きのページ」として1枚生成。仕様JSONは `scripts/sheet2-spec.json` が見本）
2. **オーナーが目視で合格判定**（キャラ・画風・日本語テキストの正確さ。不合格なら再生成 or 下のChatGPTアプリ用プロンプトへ）
3. 合格したら Claudeが `scripts/ingest-pose-sheet.mjs --start N` で自動分割 → マニフェスト登録 → 公開まで実施

コストは1枚あたり約30円。実行はGitHub Actionsの一発ワークフロー
（`.github/workflows/pose-sheet-test.yml` の形式。出力はデプロイ無効ブランチへ）。

## 予備手段：ChatGPTアプリで手動生成する場合

APIの出来が悪いときのフォールバック。ChatGPTに元画像を添付して、以下を貼る：

```
添付した画像とまったく同じキャラクター・同じ画風・同じフォーマットで、続編のストレッチ設定表を1枚作ってください。

- 4x4の16コマグリッド。各コマは「番号バッジ（17〜32）＋タイトル＋箇条書きの手順3行＋キャラクターがそのポーズを実演している絵」の構成
- キャラクター：茶色のロングウェーブヘアの日本人女性、白Tシャツ（胸に小さくZNロゴ）、水色レギンス、白ソックス
- 背景はライトグレー。全コマで顔・体型・画風を完全に統一

16コマの内容（デスクワーク・上半身編）：
17. 肩甲骨引き寄せ（椅子に座り、ひじを軽く曲げて後ろへ引き肩甲骨を背骨に寄せる）
18. 首の前倒し（両手を後頭部に軽く添え、うなずくように首の後ろを伸ばす）
19. 首の回旋ストレッチ（ゆっくり真横を向いて首すじを伸ばす）
20. あご引きエクササイズ（あごを水平に引いて頭を背骨の上に戻す）
21. 手首・前腕のストレッチ（腕を前に伸ばし、手のひらを返して反対の手で軽く引く）
22. 壁で胸を開くストレッチ（壁に前腕をつけて体を反対へひねり、胸の前を伸ばす）
23. 脇・体側のストレッチ（座って片腕を斜め上に伸ばし、体をやや横に倒す）
24. 首すじのストレッチ（片手を背中に回し、頭を斜め前に倒す）
25. こめかみほぐし（両手の指先でこめかみをやさしく円を描いてほぐす）
26. 肩回し（両肩を大きく後ろ回しする）
27. 座ったままツイスト（椅子の背に手を添えて上体をゆっくりひねる）
28. 立って体側伸ばし（両手を上で組んで真横に倒す）
29. 椅子で脱力前屈（座ったまま力を抜いて上体を前に倒す）
30. 深呼吸ストレッチ（座って胸とお腹に手を当ててゆっくり深呼吸）
31. 立って肩甲骨寄せ（後ろで手を組み、腕を斜め下に伸ばして胸を開く）
32. 足首回し（座ったまま片脚を浮かせて足首をゆっくり回す）
```

## シート3：下半身・就寝/朝編（ポーズ33〜48）※次回はAPI生成で作る

内容は以下（API生成時は `scripts/sheet2-spec.json` と同形式の仕様JSONに起こす）。
ChatGPTアプリで作る場合は同じ要領で：

```
添付した画像とまったく同じキャラクター・同じ画風・同じフォーマットで、続編のストレッチ設定表を1枚作ってください。
（キャラクター・グリッド仕様は前回と同じ。番号バッジは33〜48）

16コマの内容（下半身・就寝/朝編）：
33. お尻の4の字ストレッチ（仰向けで片足首を反対の膝にかけ、脚を胸に引き寄せる）
34. 仰向けツイスト（両膝を立てて左右にゆっくり倒す）
35. タオルでもも裏伸ばし（仰向けで足裏にタオルをかけ、脚を上に伸ばす）
36. チャイルドポーズ（正座から上体を前に伸ばして背中をゆるめる）
37. 立位前屈（膝を軽くゆるめて上体を前に垂らす）
38. しゃがんで足首ストレッチ（かかとを床につけたまましゃがむ）
39. うつ伏せ胸反らし（うつ伏せからひじで支えて胸をやさしく起こす）
40. 膝立ち腸腰筋ストレッチ（片膝立ちで骨盤を前へスライドし、脚の付け根を伸ばす）
41. 朝の全身伸び（仰向けで両手両足を対角に大きく伸ばす）
42. 壁で姿勢リセット（壁に後頭部・背中・かかとをつけて立つ）
43. 足指グーパー（座って足の指を握ったり開いたりする）
44. 足裏ほぐし（座って親指で足裏を押しほぐす）
45. 開脚して横に倒す（床で脚を開き、片腕を上げて体側を伸ばす）
46. おやすみ深呼吸（仰向けでお腹に手を当ててゆっくり呼吸）
47. 片膝抱えストレッチ（仰向けで片膝だけを胸に引き寄せる）
48. サイドランジ（立って片脚に体重を移し、内ももを伸ばす）
```

## 単発でポーズが欲しいとき（シートを作るほどでもない場合）

代替手段として、生成パイプライン（scripts/gen-stretch-illustrations.mjs・gpt-image-2）で
候補を作り、**オーナーが目視で合格を出したものだけ**ライブラリに登録する運用も可能。
記事ごとの生成はしない（画風がChatGPT版と揃わないため）。品質判断は必ずオーナーが行う。

## 記事側の運用（column-auto.yml に組み込み済み）

- 記事はライブラリのポーズから種目を選んで構成する
- 未収載の動きは挿絵なしで公開し、AI_CHANGELOG に「ポーズ未収載: ◯◯」と記録
- 週次レポートが未収載リクエストを集計してオーナーに提示 → まとまったらシート化
