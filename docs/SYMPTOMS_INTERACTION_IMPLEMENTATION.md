# SYMPTOMSインタラクション実装記録

## 実装概要

トップページの「お悩み別」を、親しみやすい人物イラストと7症状が連動するUIへ変更した。

- PC（768px以上）：左に切替イラスト、右に7項目のコンパクト一覧を配置。
- PC操作：項目の `pointerenter` またはキーボードフォーカスでイラストを更新。
- タッチ操作：項目のクリック／タップでイラストを更新。
- 各行の右端に既存詳細ページへのリンクを常時表示。
- 初期状態は01肩こり。
- 人体スケルトン、部位マスクSVG、人体へ伸びるコネクター線は使用しない。

## イラスト素材

- `public/images/symptoms/illustration-{key}.webp` 7点
  - 全素材を960 × 1260pxへ統一。1点約34〜56KB、合計約307KB。
  - 悩みページの参考イラストに登場する、グレーヘア・白シャツの中年男性を共通キャラクターとして使用。
  - 黒背景に白い輪郭線だけを残す線画へ統一し、該当する悩み箇所だけを赤い発光で表現。
  - 背景色はセクションと同じ黒。人物に肌色や衣服色は付けない。
  - 既存6点は同一人物・ポーズを保ったまま線画化。スポーツケアのみゴルフ後のポーズを新規作成。

| key | 症状 | イラストの表現 |
| --- | --- | --- |
| `shoulder` | 肩こり | 肩を押さえ、肩・僧帽筋を赤く表示 |
| `lower-back` | 腰痛・お尻や脚の張り | 腰を押さえ、腰・臀部・大腿上部を赤く表示 |
| `neck-eyes` | 首こり・眼精疲労 | 首とこめかみに手を当て、首・目を赤く表示 |
| `lower-legs` | むくみ・冷え | 座って脚に手を当て、両ふくらはぎ・足先を赤く表示 |
| `whole-body` | 疲れ・睡眠 | 座って額を支え、こめかみ・上背部を弱く赤く表示 |
| `upper-back` | 姿勢・猫背 | 猫背の側面姿勢で、上背部・肩甲骨を赤く表示 |
| `kinetic-chain` | スポーツケア | ゴルフ後にクラブを持って腰を押さえ、腰・肩を赤く表示 |

## レイアウトとモーション

- PCの見出し、リード、イラスト・一覧下端までを約773〜816pxに収め、900px高の画面でほぼ1画面表示できるようにした。
- PCのイラスト領域は約500〜549px、一覧は約449〜477px。
- 画像切替は580ms、`cubic-bezier(0.22, 1, 0.36, 1)` のクロスフェード。
- 行の高さを固定し、hoverでレイアウトが動かないようにした。
- SPはイラスト、一覧の順に1カラムで表示。

## アクセシビリティ

- 症状切替は `button` を使用し、`aria-pressed` を同期。
- 詳細ページへのリンクは既存の `SYMPTOMS` データから生成し、URLと文言を維持。
- イラストは装飾として `aria-hidden="true"`。
- `:focus-visible` のフォーカスリングを保持。
- `prefers-reduced-motion: reduce` ではクロスフェードを160msへ短縮。
