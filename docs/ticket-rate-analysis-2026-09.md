# 回数券販売率はなぜ落ちたか（2026-09-13 全面改訂）

オーナーの問い：「広告を変えて新規が増えた気がするが、回数券の販売率が落ちている。
女性比率も上がっている。販売率が下がった要因が広告の可能性はないか？」

**2026-09-13 に来店記録CSV（2026-06-20〜09-12・430件）で直接検証し、初版の結論を全面的に入れ替えた。**
初版（2026-09-12）の「女性比率の上昇が主因」「打ち手は女性コースの初回割引」は**どちらも撤回**する。
撤回の理由は本文6章。

---

## 結論

1. **落ち込みは 2026-08-17 を境に、担当7名中6名で同時に起きている。** 特定の誰かの問題ではない
2. **客層（性別・年代・経路・担当）の変化では説明できない。** どう標準化しても期待値は実績を上回る
3. **オーナーの「売れる人ほど新規が回らなくなる」仮説は正しい。** ただし落ち込みの**30%**しか説明しない
4. **その循環は指名によって不可逆になっている。** 配分の入れ替えでは、もう7枠しか動かせない
5. **最大のレバーは下位3名の育成。** 費用ゼロ・FC規約にも触れない
6. **女性の成約率は確かに低い（3.7% vs 18.4%）が、新規の8.9%しかおらず寄与は小さい。**
   しかも**女性比率の上昇はMeta広告のせいではなかった**

## 4. 女性向けには回数券を売る設計になっていない（構造・確定）

`src/pages/menu.astro:51` — **初回特別価格（新規向け最大20%OFF）は男性コースのみ。**
**オーナー確認（2026-09-12）：女性に初回割引は出していない。**

| | 初回のクロージングで出せるオファー |
|---|---|
| 男性・90分10回券 | ¥154,000 → **¥132,000**（その場で¥22,000引き） |
| 女性・90分10回券 | ¥95,700（**初回割引なし**） |

女性は都度払いも元から安い（60分 ¥8,800／男性 ¥13,200）ため、乗り換え動機も弱い。

⚠️ **単価への影響もある。** 女性の券は男性の初回価格の **72〜80%**。
実績でも 男性58本・平均¥50,884 に対し 女性1本・¥34,650。
女性比率が上がると、成約率が同じでも回数券の平均単価が下がり、損益分岐点が上振れする。

🔴 **ただし是正は自由にできない。FC契約 第11条2・3項で価格変更は本部の事前許可が必須、
違反の違約金は1,000万円**（`docs/fc-rules.md`）。

## 5. 指名ラチェット：売れる人ほど、新規が回らなくなる

**オーナーの仮説「売れた子はチケット消化の客が増える → 新規が売れない子に集まる → 売れない」は、
データで裏付けられた。**

担当別の来店構成（総来店に占める割合）:

| 担当 | 新規比率の推移 | チケ消化比率の推移 |
|---|---|---|
| **AINA**（成約38.9%） | 80% → 44% → **25%** | 17% → 56% → **75%** |
| KAYO（28.1%） | 86% → 61% → 48% | 14% → 39% → 52% |
| AYU（21.1%） | 92% → 80% → 55% | 8% → 20% → 45% |
| MIYUKA（12.1%） | 93% → 84% → 63% | 7% → 16% → 37% |
| **DAYAN**（5.6%） | 86% → 55% → **84%** | 14% → 45% → **16%** |

- 相関：**前半の販売本数 × 後半のチケ消化来店数 ＝ +0.93**
- 相関：**前半の販売本数 × 後半の新規比率 ＝ −0.74**

### ただし、これで説明できるのは30%

| 落ち込み 9.2pt の内訳 | |

| 各人が同じ客層で落ちている分 | **6.5pt（70%）** |

### そして指名が不可逆にしている

消化枠に占める指名の比率は **75% → 66% → 78.9%** と上がり続けている。

## 9月単月で見ても、女性の寄与は約1割

オーナーから「今月の新規販売率が悪いのは女性客が増えたからでは」との指摘。9月だけで検定した。

| | 新規 | 券 | 販売率 |
|---|---|---|---|
| 男性 | 23（85.2%） | 3 | **13.0%** |
| 女性 | 4（14.8%） | 0 | **0%** |
| 全体 | 27 | 3 | 11.1% |

女性比率は 6月5.6% → 7月6.7% → 8月12.6% → **9月14.8%** で、上昇は事実。
**女性は通算27人で券は1本だけ。**

**だが寄与は小さい。** 9月の女性比率が6〜8月平均（8.3%）のままなら期待3.23本（12.0%）、
実績3本（11.1%）。**差は0.8ポイント＝落ち込み8.1ptの約11%。**

**決め手：男性だけで見ても同じように落ちている。**

| 月 | 男性のみの新規販売率 |
|---|---|
| 6月 | 11.9% |
| 7月 | 20.7% |
| 8月 | **22.4%** |
| 9月 | **13.0%** |

女性を1人も含めずに 22.4% → 13.0%。**女性の増加はこの落ち込みを説明しない。**
