# FC契約で「本部承認が要ること／自由にできること」

出典：株式会社ザウルス ⇄ 株式会社ANDSYNC「加盟店契約書 Ver.11.0（監修済）」2025-02-19締結。
原本は Google Drive `40_FC規約・契約`（フォルダID `1PixJs57SW9mkzj05C1V7A07Yb_prD6aq`）。

⚠️ **契約書そのものはこのリポジトリに置かない。** 第三者との機密契約であり、
第7条3項で第三者への開示が禁じられている。ここには**判断に必要な条件だけ**を書く。
口座番号・担当者名・連絡先は転記しない。

⚠️ この要約は条文の趣旨をまとめたもので、法的判断ではない。
金額の大きい判断（違約金1,000万円が絡むもの）は**顧問弁護士に確認する**こと。

## 🔴 やってはいけない／事前承認が必須

| 事項 | 条項 | 備考 |
|---|---|---|
| **価格の変更** | 第11条2・3項 | 甲が定める範囲内の価格でのみ提供。**甲の許可なく価格を変更してはならない** |
| **独自の施術メニュー・商品の導入** | 第11条1・3項 | 施術・サービスは甲と同一。**事前の書面許可**があれば可 |
| **スタッフの雇用形態・給与・報酬形態** | 第11条5項 | **甲が取り決めた規定に従う。** 書面による事前承諾があれば例外可 |
| **商標・ロゴ・看板・営業シンボルの使用** | 第13条2項 | **用途・目的・使用頻度を問わず、必ず事前に甲の承認** |
| **顧客リスト・FC内の人脈への独自商品／サービスの営業** | 第11条8項 | 営利目的でなくても禁止。書面許可があれば可 |
| **備品・商品の仕入先** | 第11条4項 | 原則、甲および甲指定業者から。事前許可があれば他も可 |
| **契約上の権利義務・備品の第三者への譲渡** | 第20条 | 書面承諾が必要 |
| **店舗での別事業の並行実施** | 第11条7項 | 事前許可が必要。許可されても別看板・別メニューで区分すること |

**違約金：第11条9項・第19条2項・第20条3項いずれも 1,000万円＋損害賠償。**

## ✅ 加盟店の裁量でできる

| 事項 | 条項 |
|---|---|
| **広告宣伝の方法** | 第11条6項（営業時間・スタッフ数と並んで「創意工夫に基づいて自由に営業できる」） |
| 営業時間 | 第11条6項 |
| スタッフの数・シフトの組み方 | 第11条6項 |
| 什器・備品の仕入先 | 第12条（ただしデザイン・品質は甲の基準。**ユニフォームは本部指定**） |

⚠️ ただし第11条6項には但し書きがあり、**ブランドイメージに反すると甲が判断すれば指導が入り、従う義務がある**。
広告そのものは自由だが、**商標・ロゴを使うなら第13条2項の事前承認が別途かかる**。

## 固定費・都度費用

| 項目 | 金額 | 条項 |
|---|---|---|
| **ライセンス料** | **月額 10万円（税別）＝¥110,000** 前月末日までに振込 | 第6条 |
| 加盟金 | 200万円（税別）／**出店ごとに必要**・返還なし | 第3条 |
| 導入・追加研修費 | **1人あたり10万円（税別）** | 第4条2・7項 |
| 本部スタッフの派遣指導 | 1回 4万円（税別）＋交通費・宿泊費（実費） | 第9条2項 |

⚠️ **施術ベッドは1店舗あたり4台まで。5台以上にすると加盟金もライセンス料も2店舗分**（第3条4項・第6条4項）。
容量を増やす判断をするときは、ここが金額に直結する。

## 契約期間と出口

| 項目 | 内容 | 条項 |

## 支配権の変動に注意

第3条6項：代表者の変更、株式交換・株式移転、**33%を超える株主の変動**、その他組織変更で
支配権に実質的な変動があった場合、**加盟金（200万円）を新たに支払う義務が生じる**。
出資・資本政策を動かす前に必ず読むこと。

## その他

- **導入研修は1店舗あたり最低3名の参加が必須**（第4条3項）。新規スタッフにも追加研修が必要（第4条5項）
- 第4条3項に施術スタッフの属性に関する定めがある。**労働関連法規との整合は未確認のため、
  採用方針を決める前に社労士・顧問弁護士に確認すること**
- 賠償保険制度への加入義務（第6条6項）
- 開業後、甲が改善の必要を認めた場合は指導があり、従う義務がある（第9条1項）
