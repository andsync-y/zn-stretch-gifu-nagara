## 2. サイト構成の確定事項（§2.5の指示反映）
- `zakotsu`（坐骨神経痛）**独立ページは作らない** → `youtsu`（腰痛）内で「お尻・脚の張り」として扱う。
- `jiritsu` は**「疲れ・睡眠・リラックス」**に作り替え（自律神経は一般語として軽く触れる程度）。
- 症状ページは**7枚**：katakori / youtsu / kubi-ganseihiro / mukumi / jiritsu / shisei / sports。
- 同一意図のキーワード違いでのページ量産はしない（scaled content abuse回避）。
