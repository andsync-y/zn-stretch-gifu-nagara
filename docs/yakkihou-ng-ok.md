## 4. スタッフ紹介での注意

- 経歴・保有資格・実績年数は**確認できるまで創作しない**（プレースホルダ運用）。
- 「必ず女性が担当」とは断言できないため、**「女性トレーナー在籍」**と正確に表現（景表法）。
- 本部HPBにある「根本改善」等の効能断定表現は使わない（調整済みの一言のみ使用）。

## 5. 価格表記

- 通常価格からの割引を見せる場合は、**通常価格を併記**（例：`13,200円 → 3,300円（初回75%OFF）`）。
- 「初回価格は初めてご来店の方が対象」であることを明記。
- 「価格は変更となる場合があります。」の注記を料金掲出箇所に入れる。
- 表示はすべて税込。
